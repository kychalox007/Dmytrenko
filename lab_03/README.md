# Лабораторна робота №3

**Тема:** об'єктно-орієнтоване програмування.

**Мета:** переробити телефонний довідник студентів, використовуючи класи та об'єкти Python.

Клас `Student` зберігає дані студента. Клас `StudentList` керує відсортованим списком об'єктів студентів і виконує додавання, зміну та видалення записів. Клас `Utils` завантажує початкові дані з CSV та зберігає їх перед завершенням програми. Класи розміщені в окремих файлах.

Запуск програми з кореня репозиторію:

```bash
python -m lab_03.main lab_03/lab3.csv
```

Запуск тестів:

```bash
python -m pytest lab_03
```
