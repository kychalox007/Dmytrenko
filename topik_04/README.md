# Топік 4

Калькулятор приймає число, операцію та друге число. Він продовжує працювати, доки не введено `exit`.

У `request_data()` обробляється неправильне введення. Функція `divide()` обробляє ділення на нуль.

Запуск із кореневої папки репозиторію:

```bash
python -m topik_04.calculator
```

Список вбудованих винятків Python: [документація Python](https://docs.python.org/3/library/exceptions.html).
