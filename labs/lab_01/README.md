# Лабораторна робота №1

**Тема:** списки, словники, кортежі.

**Мета:** доповнити програму телефонного довідника студентів, використовуючи складені структури даних Python.

У програмі зберігається відсортований список словників. Кожен запис містить ім'я та прізвище, телефон, електронну пошту й групу. Назви полів зберігаються в кортежі.

Реалізовано додавання, зміну, видалення та виведення записів. Після додавання або зміни запис розташовується в алфавітному порядку за ім'ям. Для запуску потрібен Python 3.10 або новіший.

```bash
python labs/lab_01/lab_01.py
```
