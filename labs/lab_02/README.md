# Лабораторна робота №2

**Тема:** робота з файлами. Юніт-тести.

**Мета:** розширити телефонний довідник студентів завантаженням і збереженням даних у CSV та перевірити основні функції юніт-тестами.

Програма отримує шлях до CSV-файлу через аргумент командного рядка. Під час запуску записи завантажуються у відсортований список, а перед виходом зберігаються у файл. Підтримуються CSV-файли з полями `name` і `phone`; додаткові поля `email` і `group` можуть бути порожніми.

Встановлення pytest:

```bash
python -m pip install pytest
```

Запуск програми з кореня репозиторію:

```bash
python labs/lab_02/phonebook.py labs/lab_02/lab2.csv
```

Запуск тестів з кореня репозиторію:

```bash
python -m pytest labs/lab_02/test_phonebook.py
```
