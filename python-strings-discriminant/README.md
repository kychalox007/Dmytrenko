# Рядки та дискримінант квадратного рівняння

Навчальна робота з Python за трьома завданнями:

1. Функція `reverse_string()` повертає рядок у зворотному порядку.
2. Тести демонструють роботу методів рядків `strip()`, `capitalize()`, `title()`, `upper()` і `lower()`.
3. Функція `discriminant()` обчислює дискримінант за формулою `D = b² - 4ac`.

## Запуск прикладу

```bash
python main.py
```

## Запуск тестів

```bash
python -m unittest -v
```

У тестах перевірено обернення рядка, усі п'ять методів рядків та випадки додатного, нульового й від'ємного дискримінанта.
